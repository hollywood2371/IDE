# Курс Data Science. Дипломный проект. Задача классификации.
## «Модель прогнозирования остановки на питстоп в чемпионате автогонок в классе "Формула1"»

Ссылка страницу с датасетом: https://www.kaggle.com/datasets/sohailkhanlml/f1-strategy-dataset

## Цели и задачи проекта

Задача проекта - создать модель, которая позволит предсказывать состоится ли питстоп на следующем круге.

### В ходе работы над проектом были решены следующие задачи:

→ EDA (diplom_eda.ipynb):

    * Датасет очищен от пропущенных значений и выбросов.
    * Созданы новые признаки на основе имеющихся.
    * Произведена оценка важности признаков.
    * Произведено кодирование и стандартизация признаков.

→ Обучение модели (diplom_model.ipynb):

    * Построена модель LogisticRegression.
    * Построена модель RandomForestClassifier.
    * Построена модель LGBMClassifier.
    * Построена модель XGBClassifier.
    * Произведена оценка предсказаний каждой модели, лучшая из них сохранена в файл.

→ Подготовка к созданию прототипа (diplom_prod.ipynb):

    * Подгружена обученная модель XGBClassifier.
    * Проведена проверка на воспроизводимость.

→ Создание прототипа (папка web):

    * Создан Docker контейнер.
    * Составлена инструкция по созданию и запуску контейнера.
